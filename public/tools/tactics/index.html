Clique une icône puis le terrain pour placer (glisse pour une zone). Clique un élément pour le sélectionner/déplacer, le vide pour désélectionner — glisse sur le vide pour une zone de sélection. Maj+clic = ajouter/retirer de la sélection multiple ; glisse un élément déjà sélectionné pour déplacer tout le groupe. Maj pendant un glisser ou en posant un joueur l'aligne sur les autres et sur les axes du terrain (le repère en pointillé montre l'alignement retenu) et, sur un glisser, bride aussi le mouvement à l'axe horizontal ou vertical. Sur un joueur « corps orienté », la poignée de pivot tourne le corps, Maj par pas de 15°, double-clic pour revenir à 0°. Un objet verrouillé (K, ou le cadenas dans son panneau) reste sélectionnable et modifiable, seul son déplacement est bloqué. Raccourcis : Suppr, Cmd/Ctrl+C/V, Ctrl+glisser = dupliquer, Ctrl+Maj+glisser = dupliquer aligné, Maj+glisser/pose = aligner (+ déplacer sur l'axe en glissant), Ctrl/Cmd+Z = annuler, Ctrl/Cmd+Maj+Z = rétablir, L = bibliothèque, K = verrouiller/déverrouiller, Échap = annuler l'outil.
